# Limpieza y preparación de datos de ventas con Python y Pandas

## Descripción
Este proyecto consiste en la limpieza y preparación de un conjunto de datos de ventas, con el objetivo de mejorar su calidad y facilitar su posterior análisis.

## Objetivo
Organizar y depurar los datos para obtener información más confiable sobre las ventas y permitir que un cliente pueda visualizar y analizar mejor el rendimiento de su negocio.

## Herramientas utilizadas
- Python
- Pandas
- Power BI

## Proceso de limpieza
Durante el proceso se identificaron diferentes problemas en el conjunto de datos, entre ellos:
- Registros duplicados.
- Valores nulos o faltantes.
- Espacios innecesarios y diferencias en los nombres de las categorías.
- Formatos de fechas inconsistentes.
- Valores negativos o inválidos en cantidades y precios.
- Diferencias en la escritura de los medios de pago.

Se desarrollaron soluciones utilizando Python y Pandas para detectar, corregir y documentar estos inconvenientes.

## Resultados
Se obtuvo un conjunto de datos más organizado y consistente, preparado para su posterior análisis. Además, se documentaron los registros que requieren verificación y se agregaron observaciones con sugerencias para revisar los valores nulos o negativos, evitando reemplazar información sin contar con una fuente confiable.

## Aprendizajes
- Aprendí a realizar un proceso de limpieza de datos desde cero.
- Mejoré mis habilidades utilizando Python y Pandas.
- Aprendí a identificar inconsistencias y errores en un dataset.
- Practiqué la validación y preparación de datos para su posterior visualización y análisis.
